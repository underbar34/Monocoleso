# Мувсеты босса (Холодос)

Кратко: атаки босса — это **таймлайн событий** в JSON. Их можно править в редакторе уровней; игра читает тот же файл уровня.

---

## Связь частей

```
levels/level1.json          ← объект boss + поле moveset
        ↓
level_loader (normalize)    ← если moveset нет — берёт дефолт из каталога
        ↓
GameState.apply_level       ← state.boss_moveset
        ↓
logic.update_boss           ← фазы → выбор мува → события по кадрам
        ↓
boss_moves.apply_event      ← ракеты / slash / лёд / melee
```

Дефолтный moveset Холодоса живёт в `boss_moves.default_holodos_moveset()` и подставляется в каталог боссов (`level_loader.catalog_moveset`).  
Если в JSON у босса **нет** `moveset` — в рантайме всё равно будет дефолт.  
Если **есть** — используется он (с дополнением из дефолта при частичном оверрайде).

---

## 3 фазы

У каждой фазы:

| Поле | Смысл |
|------|--------|
| `hp_below` | Фаза активна, пока HP/max ≤ этого порога (берётся самая «жёсткая» подходящая) |
| `idle` | Пауза в кадрах между мувами (меньше = чаще бьёт) |
| `moves` | Список имён мувов из словаря `moves` |

По умолчанию:

1. `hp_below: 1.0`, idle **90** — `aim_missile`, `side_slash`
2. `hp_below: 0.66`, idle **55** — + лёд, двойной slash, melee
3. `hp_below: 0.33`, idle **30** — ярость, fan ракет, короткий простой

## Структура мува

```json
"aim_missile": {
  "duration": 70,
  "events": [
    { "frame": 8,  "action": "set_sprite", "sprite": "attack_right" },
    { "frame": 36, "action": "missile", "mode": "aim", "speed": 5.5, "count": 1 },
    { "frame": 52, "action": "set_sprite", "sprite": "idle" }
  ]
}
```

- `duration` — длина мува в кадрах (~60 FPS); после неё босс снова ждёт `idle`.
- `events` — на кадре `frame` вызывается `action` с параметрами.

### Действия (`action`)

| action | Что делает | Главные поля |
|--------|------------|--------------|
| `set_sprite` | Метка режима (тело остаётся idle-циклом) | `sprite`: idle / attack_left / … |
| `missile` | Ракета `boegolovka` | `mode`: aim / spread / ring / angle; `speed`, `count`, `spread_deg` |
| `slash_proj` | Горизонтальный удар `prostous*` | `side`: auto / left / right; `speed` |
| `melee` | Хитбокс + VFX `atakaus*` | `side`, `atk_frame` 1\|2, `duration` |
| `ice_rise` | Лёд снизу `ledholodosnis` | `target`: player / boss / arena; `offset_x`, `lifetime` |
| `shake` | Тряска босса | `amount`, `frames` |
| `end` | Досрочно закончить мув | — |

Ассеты лежат в `Assets/holodos/` и грузятся в `config.load_images`.

## Редактор уровней

```bash
python level_editor.py levels/level1.json
```

1. Выдели босса (ЛКМ).
2. Нажми **M** — оверлей мувсетов.
3. **Tab** — фокус: фаза → список мувов → события → поля события.
4. Правки:
   - **←/→** — фаза; **[/]** — idle ±5; **;/'** — `hp_below` ±0.05
   - **↑/↓** — мув или событие
   - **N** — новый мув; **R** — переименовать (в фокусе «мувы»)
   - **A** — добавить событие (выбор типа)
   - **Enter** — править поле; **[/]** или ввод + Enter
   - **,/.** — `duration` мува ±5
   - **Del** — убрать событие / убрать мув из фазы
   - **P** — схема «куда летит» для выбранного события
5. **Ctrl+S** — сохранить уровень в JSON.
6. **Esc** — закрыть оверлей.

Без **Ctrl+S** изменения только в памяти редактора — игра их не увидит.

---

## Как изменения попадают в игру

1. Сохранил уровень (**Ctrl+S**) → записался `levels/level1.json` (в т.ч. `objects[].moveset`).
2. Запустил игру (`python main.py`) → `load_level` читает этот файл.
3. Перезапуск игры обязателен после правок JSON (уровень грузится при старте забега).

Проверка в JSON: у объекта `"type": "boss"` должно появиться `"moveset": { "phases": [...], "moves": {...} }`.

Если `moveset` удалить из JSON — снова подставится дефолт из кода.

---

## Минимальный чеклист нового мува

1. В редакторе: **N** → имя → набери события (**A**) с нужными `frame`.
2. Добавь имя мува в `moves` нужных фаз (новый мув сразу попадает в текущую фазу).
3. Выставь `duration` больше последнего `frame`.
4. **Ctrl+S** → перезапусти игру → зайди в арену босса.
